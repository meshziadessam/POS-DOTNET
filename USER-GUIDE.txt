Push 1.2.1 — دليل العميل

1. شغّل PushPOS-Setup.exe. الحزمة الكاملة تتضمن .NET Framework 4.8 دون إنترنت. أثناء التسطيب أدخل اسم المطعم والتليفونات والعنوان وختام الإيصال، واختر صورة المطعم اختياريًا. اسم ملف التشغيل والاختصار يصبح باسم المطعم، مثل «مطعمي.exe».
2. بعد التثبيت ستظهر شاشة التفعيل. انسخ كود الجهاز PP1 وأرسله للبائع مع اسم العميل.
3. استورد ملف .lic الذي يصدره البائع لك. الترخيص دائم لجهاز Windows واحد.
4. أنشئ حساب المدير ثم سجّل الدخول. لا توجد كلمة مرور افتراضية.
5. المدير يضيف الموظفين من إعدادات ← النظام ← المستخدمون.
6. الصورة تظهر بجوار «شاشة الكاشير» وعلى الإيصال. لتغييرها لاحقًا: إعدادات ← النظام ← صورة المطعم / الأيقونة. بيانات المطعم: إعدادات ← النظام ← بيانات المطعم: أدخل اسم المطعم والتليفونات والعنوان وختام الإيصال. من الطباعة اختر طابعة Windows ومقاس الورق والشعار الخاص بك.

المدير يرى الإعدادات وتعديل الأوردر المحفوظ وإعادة الطباعة. الموظف لا يرى الإعدادات أو تعديل الأوردر المكتمل، لكنه يستطيع إعادة الطباعة واستكمال الانتظار.

البرنامج ينشئ قاعدة مستقلة فارغة داخل %LOCALAPPDATA%\PushPOS. لا يحتوي على بيانات مطعم سابق. خذ نسخة احتياطية بانتظام من الإعدادات واحتفظ بها خارج الجهاز.

التفعيل مرتبط بـWindows وقرص النظام. نسخ ملف التفعيل لجهاز آخر لا ينقل الترخيص. إعادة تثبيت Windows أو تغيير قرص النظام قد يحتاج إعادة إصدار من البائع. احتفظ بملف .lic منفصلًا؛ نسخة البيانات الاحتياطية لا تتضمن التفعيل. نقل البيانات لا ينقل الترخيص.

الحفظ يسبق الطباعة. إذا فشلت الطباعة لا تكرر البيع؛ استخدم إعادة الطباعة من الطلبات السابقة بعد إصلاح الطابعة.

تظهر عبارة Powerd by Ziad Essam بالرمادي تحت مسح الأوردر. تحديث البرنامج يحافظ على بيانات المطعم التي عدلها المدير؛ اسم ملف التشغيل يحدد في التسطيب.
